# 接口和状态约定

库存服务拥有商品、库存和预留记录，Node-RED 不直接访问 SQLite。

| 接口 | 成功 | 典型错误 |
|---|---|---|
| `GET /health` | 200 健康状态 | - |
| `GET /products` | 200 商品与服务端库存 | - |
| `POST /reserve` | 201 新预留，200 幂等重放 | 400 参数，404 SKU，409 缺货/规则/编号冲突 |
| `GET /reservations` | 200 记录列表 | - |
| `GET /reservations/{id}` | 200 详情 | 404 未知编号 |

工作流公开 `/api/orders` 并透传业务状态。库存服务停止、连接失败或 5xx 统一转为 502，但不会伪造成功。超时后的自动重试未启用，因为客户端不能仅凭超时判断服务端是否已经提交事务；应先按原 request_id 查询。
